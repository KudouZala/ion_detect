# SWC-PSWM 改进建议与消融实验说明（20260308）

## 零、模型架构与基线参数设计依据（model_models.py）

### 0.1 架构总览

`Model_three_system_plus` 是**三路编码 + 主 Transformer + 物理/参数双分支 + Cross-Attn + 离子匹配**的结构，所有主干维度统一为 `transformer_d_model`（= `mlp_output_dims`，建议 64）。

| 模块 | 作用 | 主要 config 键 |
|------|------|----------------|
| **voltMLP** | 电压 (B,T,1) → (B,T,D) | volt_input_dim, volt_mlp_hidden_dims, mlp_output_dims, volt_mlp_num_layers |
| **impeMLP** | 阻抗 (B,T,F,2) 展平后 → (B,T×F,D) | impe_input_dim, impe_mlp_hidden_dims, impe_mlp_num_layers；输出维由 mlp_output_dims 决定 |
| **time_embedding** | 时间位置编码，加在电压与阻抗上 | time_encoder_hidden_dims, time_encoder_num_layers；输出维 = mlp_output_dims |
| **freq_encoder** | 频率编码，加在阻抗上 | freq_encoder_hidden_dims, freq_encoder_num_layers |
| **Z_encoder** | 环境(3) + 电解槽(8) + cls_token → (B,3,D)，取最后 token 为 cls_token_feat | envMLP_*, ep_*, Z_encoder_num_layers |
| **主 Transformer** | 输入序列 = volt_output ‖ impe_output ‖ cls_token_feat，长度 1+T+T×F；输出取最后一位置 last_output | transformer_d_model, nhead, transformer_num_layers |
| **band_feat_proj** | 6 个频段幅值特征 → D，与 last_output 相加得 enhanced_last_output | 无（num_bands=6 写死） |
| **physicMLP** | enhanced_last_output → 5×D，再 influence_compress → 5 个影响因子 (θ_ca, φ_ca, θ_an, φ_an, ψ) | physic_mlp_hidden_dims, physic_mlp_num_layers；physic_embed 维由 param_embed_* 压缩为 1 |
| **param_transformer** | 输入 = cls_token_feat ‖ volt_first ‖ impe_first (长度 1+1+F)；输出取首位置 first_cls_output | param_transformer_num_layers |
| **paramMLP + param_compress** | first_cls_output → 5×D → 5 个物性 (σ_mem, α_ca, α_an, i_0ca, i_0an) | param_mlp_*, param_embed_* |
| **Cross-Attn** | query=param 分支 5 个 token，key/value=physic 分支 5 个 token；输出 cross_output，池化后用于 rule/group/high3/low3/浓度 | cross_transformer_num_layers |
| **probMLP + 残差** | physic_embed = norm(param_output + probMLP(cross_output))，与 ion_embeddings 点积 → (B,5,6) → mean → 分类 logits | probMLP_* |
| **ion_attr_embed + ion_encoder + ion_postMLP** | 静态离子属性表 → 6×D 的 ion_embeddings | ion_attr_embed_*, ion_encoder_num_layers, ion_post_* |
| **rule_head / head_group / head_high3 / head_low3** | cross_pooled → rule 空间、2 类组、高/低各 3 类 | 无额外维度参数 |

约束：`nhead` 必须整除 `transformer_d_model`；各 MLP 的 output_dim 或最后一维需与 backbone 维度一致。

### 0.2 20260308 小样本基线参数设计（约 1000 样本）

针对样本量约 1000，采用**较小容量 + 较强正则**，降低过拟合、便于消融对比：

- **data**：`num_freq_points: 63`，`num_time_points: 2`（序列长度 1+2+2×63=129，比 T=4 时更短，参数量更少）。
- **model**：骨干维度 **32**（非 64）：`transformer_d_model` = `mlp_output_dims` = 32，所有 `*_hidden_dims: [32]`，`nhead: 4`（整除 32）；各 Transformer/MLP 保持 **1 层**，`param_embed_num_layers` / `physic_embed_num_layers` 为 0。
- **train**：`weight_decay: 5e-4`（比 1e-4 略大，加强 L2 正则）；其余与常见设置一致，`eval_every: 100` 便于看验证曲线。
- **paths / dataset**：与 no_overlap 等设定一致。

**20260308a** 即上述小样本基线（完整损失）；**20260308b～g** 与 20260308a 的 data/model/train 完全一致，仅将对应 **lambda_*** 置 0 做消融。

## 一、20260308 基线（20260308a）简要

- **config**：20260308a.yaml（小样本优化）  
- **数据**：no_overlap 划分（150 测试，其余训练），`num_time_points=2`，63 频点。  
- **模型**：Model_three_system_plus，骨干 **32 维**、单层 Transformer、nhead=4；电压/阻抗/时间/频率/环境/离子等编码均为 32 维。  
- **训练**：Pair 训练，`weight_decay: 5e-4`；含 **一致性**、**单调衰减**、**极性**、rule/group/tree/band 等损失。

## 二、改进建议（相对 LSTM 分类效果拉不开时的可调点）

1. **时间点与序列信息**  
   - 小样本基线使用 `num_time_points: 2` 以控制序列长度。若验证集表现稳定，可尝试改为 4 以增加时序信息。

2. **Pair 与物理约束权重**  
   - 若与 LSTM 差距不大，可能是 pair/物理项权重偏小，分类主导一切。  
   - 可适当增大：`lambda_consistency`、`lambda_monodec`（如 1e-3～5e-3），观察验证集准确率与 loss 曲线。

3. **电压损失权重 alpha**  
   - 当前 `alpha: 0.05`，电压 MSE 较弱。  
   - 可尝试提高到 0.1～0.2，加强“电压预测 ↔ 物理参数”的耦合，让物理结构更起作用。

4. **模型容量**  
   - 当前基线为 `d_model: 32`、单层，适合约 1000 样本。若欠拟合，可尝试 `d_model: 64` 或 `transformer_num_layers: 2`（需同步改各 MLP 的 hidden_dims 与 mlp_output_dims）。

5. **规则与层次结构**  
   - rule/group/tree 是否必要可通过 20260308e、20260308f 消融验证；若去掉后明显变差，说明这些设计重要。

6. **训练与早停**  
   - 已设 `eval_every`，建议结合验证集准确率/F1 曲线决定是否早停或减少 `num_epochs`，避免过拟合。
